THE ONE FILE

In the End, there can be only one.

There can only be One File. Map networks, smart homes, sports plays, mind maps, infrastructure or anything with nodes and connections. Animated zones, replay video export, enterprise encryption, full styling. Works offline, opens anywhere, saves into itself.

The Networkening edition adds live status monitoring and icons from selfh.st/icons, MDI, and Simple Icons. Still one file.

TheOneFile Verse adds an easily deployable, Docker based, real time collaboration wrapper that enables multiple users to create, edit and share together.

Forged in Code

Zero Config

No install, no setup, no dependencies. Zero coding knowledge required. Just open the file.

Enterprise Encryption

AES 256 GCM with PBKDF2, 200,000 iterations. Browser native Web Crypto API. Zero server communication. Non recoverable by design.

Works Everywhere

Chrome, Edge, Firefox, Safari desktop and mobile. Modern Android and iOS browsers. Offline first.

Canvas and Navigation

Large zoomable and pannable workspace. Minimap with viewport tracking. Clear grid and boundary indicators. Right click context menu.

Draw Anywhere

Add text labels, boxes, and custom lines to annotate your topology. Free draw mode with polylines, rectangles, and styled text.

Nodes and Shapes

Multiple shapes for servers, routers, switches, firewalls, and clouds. Editable name, IP, role, tags, and notes. Resizable with full styling.

Rack Topologies

Create rack nodes for physical server racks. Assign devices to specific U positions. Visual capacity indicator shows available vs used space.

Smart Connections

Smart routed lines between nodes. Multiple links between devices. Direction arrows, custom width, color, labels, and port labels.

Layer System

Physical, logical, security and application layers. Toggle visibility to focus on specific aspects of your topology.

Lock and Group

Lock nodes to prevent accidental movement. Group related nodes to move them together. Visual indicators for both states.

Bulk Operations

Multi select for batch operations. Bulk align, distribute, clone, delete, lock, and group. Desktop and mobile toolbars.

Full Keyboard Control

Arrow key nudging for pixel perfect positioning. Tab cycling through nodes. Undo, redo, copy, paste, zoom, and more.

Mobile Optimized

Completely rewritten mobile UI. Resizable footer with drag handle. Touch optimized controls. Double tap gestures. Responsive layout.

Recording and Replay

Record topology changes in real time or step by step. Play back recordings. Export as animated video.

Save System

Exports a brand new updated HTML file. All data embedded in the file. Optional AES 256 GCM encryption. No servers involved.

Live Monitoring Networkening

Live status indicators on nodes. Manual or auto ping with configurable intervals. Status scheduling with timer and last run tracking.

10,000+ Icons Networkening

MDI, Simple Icons, and selfh.st icon libraries. Editable icon shapes on every node.

Real Time Collaboration Verse

Multi user real time editing. Docker based deployment. Admin dashboard. Shared topology server with persistent storage.

Summon the Verse

Deploy collaborative topology editing with a single command.

TERMINAL
# Quick start docker run -d -p 10101:10101 -v theonefile-data:/app/data \ ghcr.io/gelatinescreams/theonefile_verse:latest
DOCKER COMPOSE
services: theonefile_verse: image: ghcr.io/gelatinescreams/theonefile_verse:latest ports: - "10101:10101" volumes: - ./data:/app/data restart: unless-stopped

Then run: docker compose up -d and open http://localhost:10101
